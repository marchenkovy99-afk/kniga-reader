# Книга

Личная читалка FB2, FB2.zip, EPUB без DRM и TXT. Черновая версия для iPhone и компьютера.

- Режим без панелей при открытии книги: центральное касание показывает или скрывает управление, касание слева листает назад, справа вперёд, свайп вправо листает назад, влево вперёд; перелистывание не открывает панели. Escape переключает панели с клавиатуры.
- Реальное перелистывание с изгибом страницы и тенью (StPageFlip), кнопки и клавиатура; системное уменьшение движения.
- Размер текста 12–48 px, межстрочный интервал 1–2.5, боковые поля 8–72 px, абзацные/буквенные интервалы, отступ первой строки, выравнивание и темы.
- Разбиение по измерениям DOM с сохранением исходного текста и форматирования; позиция привязана к блоку и символу.
- Поиск, оглавление, примечания, закладки, локальные оригиналы в IndexedDB.
- Изолированное облако в R2 через Sites; идентификация ChatGPT на сервере, отдельное пространство каждого пользователя. Устройства хранят независимые состояния; закладки объединяются с учётом удаления. Открытая книга не перескакивает при синхронизации.
- Все поля ввода не меньше 16 px; пользовательское масштабирование разрешено.

## Запуск

Node.js 22.13+.

```sh
npm ci
npm run build:reader
npm run dev
```

Облако требует привязки BUCKET и доверенных заголовков Sites. В обычном локальном запуске без входа читалка работает локально, а облачный API возвращает 401. Не имитируйте заголовки идентификации в публичном прокси.

```sh
npm test
npm run check
npm run build
```

## Структура

`reader/src/` — интерфейс, импорт, пагинация, локальное хранение и синхронизация. `app/api/cloud/` — защищённый облачный API. `server/cloud.ts` — проверка входа, происхождения запросов, размеров и разделение пространства. `tests/` — регрессии импорта/безопасности/синхронизации. `public/reader/` — сгенерированная клиентская сборка, обновляется `build:reader`.

## Ограничения черновика

20 МБ на файл, 60 МБ после распаковки и 2 млн символов. Нет PDF, DRM и EPUB с фиксированной вёрсткой. Издательский CSS EPUB заменяется оформлением читалки; SVG/MathML и внешние ресурсы не исполняются, об их отсутствии сообщается. Сохраняется исходный файл. Большие таблицы могут потребовать уменьшить шрифт.

Системные шрифты и автоматические переносы зависят от устройства. Точная проверка отсутствия приближения Safari требует настоящего iPhone: мобильный размер окна настольного браузера этого не доказывает.

Встроенная «Капитанская дочка» — явно обозначенный короткий демонстрационный фрагмент. Полные книги добавляет пользователь.

## GitHub Pages и Supabase

Сборка: `npm run build:pages`, публикация ветки `main`, папки `/docs`.
Вход в «Облако»: почта и пароль Supabase Auth. Книги: закрытый бакет `kniga-books`, метаданные `kniga_books`, состояния устройств `kniga_states`. RLS ограничивает операции владельцем. Опубликован только publishable key.
Схема: `supabase/reader-schema.sql`. Приложения трекеров используют отдельные таблицы. Существующее облако Sites не мигрируется автоматически: добавьте книги в библиотеку Pages и войдите в Supabase.

## Версия 0.2

Ускоренное повторное открытие и перелистывание благодаря кешу разметки и постепенной загрузке соседних страниц; панели поверх страницы не меняют размер текста. Настройки оформления отдельно для каждой книги, пресеты «Роман», «Нонфикшн» и «Компактно», светлые, ночная, OLED и автоматическая темы. Библиотека со статусами, сортировкой, коллекциями, резервным копированием и восстановлением. При чтении доступна приблизительная оценка оставшегося времени, поиск по главам. Выделение текста, заметки и экспорт цитат в Markdown, синхронизация с объединением правок по идентификаторам. Поддержка выделения многоабзацных фрагментов зависит от Safari.
