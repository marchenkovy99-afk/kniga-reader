# Книга: черновая читалка

Пользователь одобрил создание черновика по показанному референсу. Главный сценарий: импорт собственной FB2/FB2.zip/EPUB/TXT, чтение и широкая настройка текста без потери содержимого. Веб-приложение для iPhone, адаптивное на компьютере. Русский интерфейс, бумажный фон, PT Serif/system serif для книги, системный sans для управления, зелёный акцент. Никаких декоративных виджетов.

Подходы: простая прокрутка надёжна, но не даёт требуемого переворота. CSS-поворот плоского листа недостаточно похож на книгу. Выбран StPageFlip с настоящим изгибом, HTML-страницами и касаниями; контент заранее разбивается на страницы измерением DOM. Открытие книги и панелей: 220–300ms; перелистывание: 550ms; reduced motion отключает пространственные эффекты.

Размер текста 12–48px, межстрочный 1–2.5, боковые поля 8–72px с защитой минимальной ширины текста; отдельные абзацные/буквенные интервалы, выравнивание, переносы, шрифты, темы. При изменении настроек и размеров окна страницы пересчитываются, позиция хранится как ID блока и смещение символа. Размеры интерфейса не зависят от размера книги.

Новые книги и исходные файлы сохраняются в IndexedDB, настройки и позиция отдельно. Нет отправки книг на сервер и межустройственной синхронизации. Ошибка хранения всегда видна. Импорт XML/ZIP с ограничением размера, запретом DTD и исполняемого содержимого; изображения только локальные растровые. EPUB без DRM и фиксированной вёрстки, без обещания сохранения издательского CSS. Некорректные/неподдерживаемые книги отвергаются целиком, без тихого усечения текста. 20MB файл, 60MB распаковка, 2M символов.

Готовность: тесты импортера, безопасности и якорей; сборка; проверка реального UI, импорта, полей, текста, перелистывания, перезагрузки, тем и ошибок. GitHub: marchenkovy99-afk/kniga-reader, private. Публикация частного черновика через Sites.

## Добавление облака по запросу пользователя

Облачная синхронизация добавлена после первоначального черновика. Изменение общего проекта Supabase было отклонено автоматической проверкой из-за неподтверждённого выбора проекта с чужими для читалки приложениями. Эта миграция не применена и повторно не выполняется. Безопасная альтернатива: изолированный R2 BUCKET самого нового частного Site, без изменения существующих приложений. Серверная идентификация через Sites/ChatGPT, отдельные пространства пользователей. Исходные книги неизменяемы и адресуются SHA-256, синхронизация состояния отдельно для каждого окна/устройства с ETag. Закладки объединяются, удаление содержит отметку времени. Во время чтения удалённое место применяется только по явному выбору.

Safari: все input/select/textarea не меньше 16px, viewport без запрета zoom. Проверка реального iOS Safari недоступна в настольном cloud browser и не заявляется выполненной.
