# Книга: библиотека и тёмная тема

Запрос: убрать вертикальный промежуток между абзацами, переработать оболочку приложения, сохранить экран чтения и Supabase. Целевое устройство: iPhone.

Выбранное решение: компактная мобильная библиотека. Шапка с логотипом, темой и облаком; заголовок с добавлением книги; полноценное поле поиска; один блок продолжения; сетка обложек без карточек вокруг текста. Слоганы и повторный блок импорта удалены. Сохранены все действия и данные. Альтернативы: список строк хуже показывает обложки; крупная витрина сохраняла бы избыточные размеры текущей версии. Это выбор исполнителя в рамках порученного редизайна.

Светлая оболочка: нейтральный белый, графитовый текст, сдержанный зелёный акцент. Тёмная оболочка: графитовые поверхности, светлый текст, спокойный зелёный акцент; цвета заданы ролями. Кириллический системный шрифт. Кнопки от 44 CSS px. Анимации короткие и отключаются при reduced motion.

Тема доступна из библиотеки и сохраняется существующим механизмом настроек. Палитра и геометрия книжной страницы сохранены. Старые настройки абзацного интервала мигрируются на 0 один раз; последующая ручная настройка остаётся доступной. Исходный текст, отступ первой строки, якорь чтения и синхронизация сохраняются.
