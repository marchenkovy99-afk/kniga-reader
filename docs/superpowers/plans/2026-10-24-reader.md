# Reader Implementation Plan

**Goal:** Create a private usable ebook-reader draft following approved visual reference.
**Architecture:** Static Vite application; safe structured book model, IndexedDB originals, DOM-measured pagination and StPageFlip. No book uploads or backend.
**Tech Stack:** JavaScript, Vite, fflate, page-flip, node:test.
**Spec:** docs/superpowers/specs/2026-10-24-reader-design.md

## Constraints
12–48px font, line height 1–2.5, margins 8–72px; original file retained; anchored position; no silent truncation. 20MB input / 60MB expansion / 2M characters.

## Review Focus
- Namespace and CP1251 FB2, inline formatting and notes.
- EPUB spine order, relative image/link paths, malicious markup and ZIP expansion limits.
- Oversized text at narrow widths, long paragraphs and whitespace at page boundaries.
- Resize / settings races and anchored position after restart.
- IndexedDB errors, missing network, reduced motion and keyboard navigation.

- [ ] 1. Write failing import/security/anchor tests, run; implement safe book parser and anchor utilities; rerun.
- [ ] 2. Implement library, persistent originals, controls and DOM pagination; verify exact text reconstruction and no clipped content in browser.
- [ ] 3. Integrate physical page turning and transitions; test next/previous, settings, reload, themes, errors.
- [ ] 4. Run suite, syntax checks, build, dependency audit and UI review; push exact source to GitHub and Sites; publish and deliver limitations.
